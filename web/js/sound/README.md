# 소리

효과음과 배경음악을 내는 곳. 소리 세션이 맡는다. 화면 쪽은 `index.js` 만 부른다.

## 화면에서 부르기

```js
import { sfx } from "../sound/index.js";

sfx("throw", hand); // 손을 냈을 때. hand 는 도감의 손 객체(가위는 싹둑, 바위는 딱, 보는 책장, 나머지는 톡)
sfx("count", 3); // 셋을 셀 때 한 마디마다. 3 은 세는 마디 수
sfx("reveal"); // 손을 공개할 때. sfx("reveal", "win") 처럼 판 결과를 같이 주면 뒤이어 결과 가락이 난다
sfx("win"); // 판 결과: "win" · "lose" · "draw". 값으로 줄 때는 sfx("result", cmp) (cmp 는 1, 0, −1)
sfx("matchwin"); // 경기 끝: "matchwin" · "matchlose" · "match"(승패가 없을 때)
sfx("go"); // 지금 눌러야 할 때(먼저 누르기 놀이의 '치기!' 같은 글 바로 뒤). 방금 건 승패 가락 대신 이 소리가 난다
sfx("right"); // 빠르게 잇달아 답하는 놀이의 맞음과 틀림: "right" · "wrong"
```

- 꺼져 있거나 아직 누른 적이 없으면 아무 일도 하지 않는다. 소리 때문에 오류가 나서 화면이 멈추는 일은 없다.
- 단추와 링크를 누르는 소리는 `index.js` 가 알아서 낸다. 누른 단추가 위의 소리를 냈으면 겹쳐 내지 않는다.
- 겹치는 차례는 엔진이 정리한다.
  - 결과 가락은 공개 소리 0.3초 뒤에 나온다. 새 손, 새로 세기 시작, 공개, 새 가락이 오면 앞 가락은 거둔다.
  - 같은 순간에 판 결과와 경기 끝을 같이 부르면 경기 끝 가락만 난다. 경기 끝 가락이 울리는 동안에는 판 가락을 내지 않는다.
  - 손을 내자마자 세기 시작하면 손 내는 소리가 첫 마디를 대신한다. 그래서 손 내는 소리는 `onPick` 같은 다음 일보다 먼저 부른다.
- 무대의 `say(글, "win" | "lose")` 는 승리·패배 가락을 낸다. 그 글이 결과가 아니라 누르라는 신호면 바로 뒤에 `sfx("go")` 를 부른다.
- 소리는 화면에 이미 보이는 것을 한 번 더 알릴 뿐이다. 소리로만 전하는 것은 두지 않는다.

지금 소리를 부르는 곳:

- `ui/widgets.js`: 손 단추(`handGrid`), 외치기(`chant`: 마디마다 세는 소리, 끝에 공개), 무대의 승패 글(`say`).
- `views/matrix.js`(무승부, 경기 끝), `views/home.js`(바로 한 판), `online/room.js`(세기, 공개와 판 결과, 경기 끝), `online/challenge.js`(도전장 결과).
- 놀이 화면: 무승부나 다시 하는 판에 `draw`, 놀이가 끝날 때 `matchwin`·`matchlose`·`match`.
  묵찌빠, 아치무이테호이, 글리코, 한정, 다이너마이트와 물풍선, 뿅망치, 돈파파, 릴레이, 황제와 노예, 모라, 블로토 대령, 여럿이, 진행자 이기기, 술래잡기, 장기.
  - 한 번 겨뤄 끝나는 놀이(하나빼기, 페니의 게임, 비추이 주사위)는 끝에도 판 가락(`win`·`lose`·`draw`)을 낸다.
  - 먼저 누르기 신호 `go`: 뿅망치('치기!'·'막기!'), 돈파파('같음!'), 술래잡기('달아나기!').
  - 손 단추를 따로 그리는 화면은 `throw` 를 직접 부른다: 하나빼기(남길 손), 편 가르기.
  - 명령 가위바위보는 답마다 `right`·`wrong`, 끝에 `match`(새 기록이면 `matchwin`).
  - 여럿이는 판마다 나에게 어땠는지(`roundTone`)에 맞춰 낸다. 남은 사람끼리 마저 하는 동안에는 끝 가락만 난다.

## 배경음악

- 설정의 `music` 이 켜져 있으면 저절로 흐른다. 화면이 부를 것은 없다. 끄면 0.2초쯤에 걸쳐 사그라들고, 다시 켜면 여는 마디부터 다시 한다.
- 언제 시작하나: 브라우저(크롬·사파리·파이어폭스 모두)는 그 쪽에 첫 손짓이 있기 전의 소리를 막고, 사이트가 이것을 풀 길은 없다.
  - 처음 연 탭, 브라우저가 새로 고친 쪽(F5): 화면 어디든(빈 곳이어도) 첫 손짓에 시작한다.
    브라우저가 손짓으로 쳐 주는 것은 마우스를 누르는 순간(떼기 전), 손가락을 뗄 때(톡), 글쇠(Shift·Ctrl·Esc 는 아니다)다.
    마우스를 움직이거나 굴리는 것, 손가락으로 쓸어 넘기는 것은 쳐 주지 않아서 그때는 시작할 수 없다(크롬 153 에서 하나씩 봤다).
  - 브라우저가 허락하는 때에는 손짓 없이 바로 시작한다: 같은 사이트의 링크나 단추로 넘어온 쪽(개인정보 처리방침에서 돌아올 때, 앱의 '새로고침' 단추),
    사용자가 그 사이트의 소리를 허락해 둔 브라우저(크롬의 사이트 설정 → 소리 → 허용), 설치한 앱.
  - 허락됐는지는 `engine.js` 의 `canAutoplay()` 가 알아본다. 소리 없는 0.1초 녹음을 틀어 보고(막히면 조용히 거절된다), 파이어폭스는 `getAutoplayPolicy` 로 묻는다.
    AudioContext 를 열어 놓고 보지 않는 것은 막혔을 때 콘솔에 경고가 남을 수 있어서다. 가려진 탭에서는 보일 때까지 시작하지 않는다.
- 곡은 사용자가 고른 시안 ⑦(나무 책상)의 네 마디를 첫머리로 삼아 키운 것이다. 사장조, 1분에 100박.
  마림바 세 줄(가락·반주·베이스)에 책상 위 물건(책 덮는 쿵, 책상 톡, 손뼉, 가위, 책장 넘기기)으로 치는 리듬.
  여는 네 마디(한 번) → 가 8마디 → 나 8마디 → 가′ 8마디 → 쉬어 가는 4마디를 되풀이한다(한 바퀴 67초).
- 악보는 `music.js` 의 `SCORE` 에 글로 적혀 있다. 한 마디가 글 한 줄, 한 칸이 8분음표, `.` 은 쉼, `-` 는 앞 음을 이어 간다.
  리듬 줄의 글자는 t 쿵, k 톡, c 손뼉, s 싹둑, p 책장. 마디마다 화음(`chords`)을 같이 적는다.
  `tests/sound.test.mjs` 가 조 밖의 음, 화음에 안 맞는 반주·베이스, 줄마다의 음역, 마디 수를 잡아 준다.
- 결과 가락(승리·패배·무승부·경기 끝)이 울리는 동안에는 배경음악을 절반(−6 dB)으로 낮췄다가 되돌린다.
- 크기는 `engine.js` 의 `MUSIC_LEVEL`(0.43). 한 바퀴 전체가 A 가중 −35 dB 쯤이다(효과음은 가장 큰 0.1초가 −21 ~ −30 dB).
- 박은 오디오 시계로만 센다. 1초 앞까지 미리 걸어 두고 0.25초마다 채운다.
  탭이 가려지면 오디오와 같이 멈췄다가 그 자리에서 이어 가고, 화면이 한참 멈췄다 돌아오면 밀린 칸은 버리고 박자 그대로 이어 간다.

## 설정

```js
import { soundState, setSound, onSoundChange, onFirstSound, HAS_MUSIC } from "../sound/index.js";

soundState(); // { sfx: true, music: true, volume: 0.8 }
setSound({ music: false }); // 배경음악 끔. 켜는 것은 누른 그 자리(click 안)에서 부른다. 이 브라우저에 남는다
setSound({ volume: 0.5 }); // 0~1. 효과음과 배경음악에 같이 걸린다. 효과음이 켜져 있으면 그 크기로 한 번 들려준다
const off = onSoundChange((s) => {}); // 바뀔 때마다(다른 탭에서 바꿔도) 부른다. off() 로 그만 듣는다
onFirstSound(() => {}); // 이 쪽에서 첫 소리(효과음이든 배경음악이든)가 날 때 한 번 부른다('소리 켜짐 · 끄기' 알림에 쓴다)
HAS_MUSIC; // 배경음악이 들어 있는가. 지금은 true(소리 단추가 배경음악 줄을 보인다)
```

- 저장하는 곳은 `ui/store.js` 의 설정: `ursp.set.sound.sfx`, `ursp.set.sound.music`, `ursp.set.sound.vol`.
- 처음 온 사람은 효과음과 배경음악이 둘 다 켜져 있다(사용자 11-12). 머리글의 소리 단추(`ui/sound-btn.js`, 프론트엔드)로 켜고 끈다.
- 주소로도 바꿀 수 있다: `?sound=1`·`?sound=0`(효과음), `?music=1`·`?music=0`(배경음악). 예: `…/ultimate-rsp/?music=0`.
  붙인 값은 이 브라우저에 남고, 주소에서는 바로 지워진다.
- `onFirstSound` 는 그 누름(click)이 끝난 뒤에 부른다. 배경음악은 마우스를 누르는 순간(click 보다 먼저)에 시작하는데,
  그 사이에 누른 단추의 안쪽을 다시 그리면 브라우저가 그 click 을 버리기 때문이다. 누르고 있는 동안에는 미뤘다가 뗀 뒤에 부른다.
- 다 끄면 엔진과 오디오 장치를 놓는다. 꺼 둔 것은 받지 않는다:
  효과음을 끈 사람은 효과음 녹음을, 배경음악을 끈 사람은 `music.js` 와 배경음악 녹음을, 둘 다 끈 사람은 `engine.js` 도 받지 않는다.

## 파일

- `index.js`: 앞문. 첫 화면에 같이 실리므로 가볍게 둔다(13KB 아래). 설정, 단추 소리, 오디오 열기(첫 손짓에, 허락된 곳에서는 바로), 엔진을 뒤늦게 받기.
- `engine.js`: 소리를 만든다. 나무토막·마림바·손뼉·단추 소리는 Web Audio 로 그 자리에서 만들고, 물건 소리는 `web/sound/` 의 녹음을 튼다.
  배경음악이 지나는 길(크기, 가락 때 낮추기)과 켜고 끄기(`setMusic`)도 여기에 있다.
- `music.js`: 배경음악의 악보(`SCORE`)와 연주(`createMusic`). 악기는 `engine.js` 의 것을 쓴다. 엔진이 배경음악을 켠 사람에게만 뒤늦게 부른다.
- `web/sound/*.wav`: 녹음 11개. 모두 CC0 이고 출처는 `web/sound/LICENSE` 에 있다. 16비트 한 채널 WAV, 모두 합쳐 200KB 아래.
  넣거나 뺄 때는 `engine.js` 의 `SAMPLES`(와 `SFX_SAMPLES`·`MUSIC_SAMPLES`), `LICENSE` 를 같이 고친다(`tests/sound.test.mjs` 가 맞는지 본다).

## 고칠 때

- 소리 크기는 귀로만 맞추지 않는다. `OfflineAudioContext` 로 뽑아 잰다.
  효과음은 가장 큰 0.1초의 A 가중 크기(값은 `engine.js` 의 짜임 위에 적혀 있다), 배경음악은 한 바퀴 전체와 마디마다의 A 가중 크기.
- `node --test tests/sound.test.mjs` 는 가짜 AudioContext 로 무엇이 언제 걸리는지와 악보만 본다. 실제 화면에서는 브라우저로 따로 본다.
- 소리 코드에서 `t(...)` 라는 이름의 함수를 쓰지 않는다(`tests/i18n.test.mjs` 가 `web/js` 의 `t("…")` 를 번역 열쇠로 읽는다). 때는 `at` 으로 쓴다.
