# 이모트 그림

온라인 대전의 이모트 8개(온라인 규약 1.4: hi, gg, good, wow, lol, hmm, oops, cry). 파일 이름은 이모트 id.
Microsoft [Fluent UI Emoji](https://github.com/microsoft/fluentui-emoji) 의 Color 판을 64×64 viewBox 에 감싼 것이다(MIT, 고지문은 `LICENSE-fluentui-emoji.txt`). 디자인 세션이 고르고(온라인 시안 ③ 고리), 화면은 `web/js/online/emotes.js` 가 `<img>` 로 넣는다.
파일에 붙은 `<metadata>`(C2PA 출처 정보)는 지우지 않는다. 그림을 바꾸면 `emotes.js` 의 `ICON_VERSION` 을 올린다(캐시).
