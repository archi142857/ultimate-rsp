# 인물 그림(전략의 진화)

'전략의 진화'의 인물 9명. 파일 이름은 `bot-<봇 id>.svg`(web/js/core/bots.js 의 id).
디자인 세션이 Microsoft [Fluent UI Emoji](https://github.com/microsoft/fluentui-emoji) 의 Color 판 동물에 역할 소품을 얹어 64×64 viewBox 로 만들었다(MIT, 고지문은 `LICENSE-fluentui-emoji.txt`, 만든 도구는 공유폴더 `자료\그림_도구\evo_cast.py`). 화면은 `web/js/views/evolution-story.js` 가 `<img>` 로 넣는다.
파일에 붙은 `<metadata>`(C2PA 출처 정보)는 지우지 않는다. 그림을 바꾸면 `evolution-story.js` 의 `CAST_VERSION` 을 올린다(캐시).
